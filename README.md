# 🏓 Pong Rétro

Un Pong en JavaScript pur (HTML5 Canvas), style arcade fin années 70 / début années 80 — palette synthwave néon, police pixel, sons 8-bit générés en direct via Web Audio API. Aucune dépendance externe (pas de framework, pas de fichier audio/image).

**[▶ Jouer en ligne](#)** 

https://byjpe.github.io/retro-pong-70/

## Fonctionnalités

- Mode **1 joueur** contre une IA (3 niveaux : facile / normal / difficile)
- Mode **2 joueurs** en local
- Contrôles clavier (desktop) **et** tactile (iPhone / Android)
- Sons 8-bit synthétisés (rebond, impact raquette, point marqué)
- Pause en jeu avec retour au menu principal
- Responsive, optimisé pour mobile (safe-area iOS, pas de scroll parasite)

## Contrôles

| Action | Clavier | Tactile |
|---|---|---|
| Raquette 1 | `W` / `S` | Glisser sur la moitié gauche de l'écran |
| Raquette 2 (mode 2 joueurs) | `↑` / `↓` | Glisser sur la moitié droite de l'écran |
| Pause | `Échap` ou `P` | Bouton ⏸ en haut à droite |

## Lancer le projet en local

Aucune installation requise — un seul fichier HTML autonome.
